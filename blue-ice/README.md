# 蓝冰猎影：宇宙幽灵 · 第一关

> 南极冰下中微子观测站 · 原创科幻合成塔防小游戏
> 纯前端实现，**零依赖、零构建、零外部素材**。所有画面与音效均由代码实时生成。

---

## 一、运行说明

### 方式 A：直接打开（最简单）
双击 `index.html`。所有脚本使用传统 `<script>` 标签加载（无 ES Module、无 fetch），因此 `file://` 协议下可以直接运行。

### 方式 B：本地静态服务（推荐，方便手机访问）
```bash
cd blue-ice
python -m http.server 8765 --bind 0.0.0.0
```
- 电脑：打开 `http://127.0.0.1:8765/`
- 手机：与电脑同一 Wi-Fi，打开 `http://<电脑局域网IP>:8765/`

### 方式 C：部署到任意静态托管
把整个目录原样上传即可，无需构建步骤、无需后端。

**环境要求**：现代浏览器（Chrome / Edge / Safari / Firefox）。音效需在首次点击「进入观测站」后由浏览器激活（Web Audio 自动播放策略）。

## 二、操作

| 操作 | 效果 |
|---|---|
| 点击**发光的空钻孔** | 消耗光子预算，随机部署一座装置 |
| 点击「部署探测器」 | 由游戏自动挑选当前最优钻孔并部署 |
| 点击已部署装置 | 打开信息卡（等级 / 伤害 / 射程 / 地形加成） |
| 拖动装置到**同种同级**装置 | 合成升级（Lv.1 → Lv.5） |
| 拖动装置到空钻孔 | 重新布阵（移动位置） |
| 「一键合成」 | 自动找一对可合成装置完成合成 |

| 「立即开始」 | 跳过波间准备期，额外 +10 光子 |
| 顶栏按钮 | 音效开关 / 1×·2× 速度 / 暂停 / 装置手册 |
| 键盘 | `D` 部署 · `M` 合成 · `空格` 暂停 · `Esc` 取消选中 |

## 三、玩法机制

### 3.1 五类光学探测装置（能力互不重叠）

| 装置 | 科学原型 | 战斗定位 |
|---|---|---|
| **DOM 光学模块** | 数字光学模块 / 光电倍增管 | 稳定单体脉冲 |
| **级联阵列** | 粒子级联簇射（shower） | 范围溅射爆发 |
| **μ 子径迹仪** | μ 子长径迹重建 | 直线贯穿多目标 |
| **符合触发器** | 多重符合触发（压低暗噪声） | 减速 + 标记增伤 |
| **量子增益器** | 高量子效率 / 阵列增益 | 邻位光环 + 产出光子 |

### 3.2 冰层地形
- **纯净深冰**（青）：光衰减小，伤害 +25%
- **共振冰**（紫）：触发更快，攻速 +30%
- **气泡层**（青绿）：散射延展，射程 +35%

第一关只完成 **17 个钻孔**（亮色），其余暗色冰层尚未钻探。空间是稀缺资源——这是布阵策略的根基。

### 3.3 经济与合成
- 初始 130 光子；部署基础成本 20，**每累计部署 5 次 +5**（按钮实时显示，规则透明）。
- 滤除干扰、波次结算、增益器都会产出光子。
- 两座同种同级装置可合成升到 Lv.5，伤害 / 射程 / 攻速 / 光效同步增强。
- 抽卡带保底：场上已有可合成对时，提高抽到同类的概率，减少纯运气挫败。

### 3.4 关卡节奏
- **12 波**：前 8 波建立信心，第 9 波起额外升压，第 5 波为精英波。
- **第 12 波 BOSS「宇宙幽灵」**：高能中微子事件，超高血量，沿裂隙推进；每约 4.8 秒释放「幽灵脉冲」使 3 座装置短暂离线并召唤次级噪声；血量每下降 25% 追加一次脉冲。**它抵达数据链路即直接失败**。
- 击破 BOSS → 全屏切伦科夫蓝光爆发 → 捕获事件 → 星级结算（到达波次 / 滤除数 / 合成次数 / 最高等级 / 科学笔记）。
- 数据链路归零 → 失败结算，可一键重开。
- 波间准备期可「立即开始」换光子，也可 2× 加速，节奏由玩家掌控。

## 四、设计说明（核心玩法原子拆解）

- **核心动词**：**布**。玩家最常做的动作是把随机到手的装置放进有限的钻孔。
- **基础规则**：① 花光子在空钻孔随机部署；② 两座同种同级合成升一级；③ 干扰粒子沿裂隙涌向数据链路，装置自动攻击；④ 守住 12 波（含 BOSS）即胜，链路归零即败。
- **涌现复杂度**：来自「随机抽取序列 × 17 个有限格位 × 合成时机 × 三种地形 × 递增成本」的组合。玩家要同时算两笔账：**铺开还是合成**、**哪个塔配哪块冰**。
- **张力结构**：短期是「这一波挡不挡得住」，长期是「把阵列养成能扛 BOSS 的最优形态」；递增成本与格位上限让两者始终互相拉扯。
- **经典对标**：最像 **《俄罗斯方块》** —— 不可控的随机件、有限空间、随时间递增的压力，玩家把无序整理成有序；合成那一下的连锁快感则来自 **《三消》**。不是照搬，而是取「随机 + 空间整理 + 时间压力」这一结构，再用合成塔防的语言重述。
- **减法优先**：开发过程中把可放置格从 28 个砍到 17 个、收紧经济、把压力集中到第 9–12 波，而不是继续叠加系统。诊断过程见 `tests/balance_report.json`。

### 科学灵感
真实 IceCube 在南极冰下 1450–2450 米布置 5000+ 个光学模块，捕捉中微子相互作用产生的次级带电粒子在冰中超光速运动时发出的**切伦科夫蓝光**，用光子到达时间反推方向与能量。大气宇宙线 μ 子与 DOM 暗噪声构成压倒性背景。本作把「用符合触发滤除背景、留下稀有事件」艺术化为塔防：敌人是背景干扰，BOSS 是那次高能事件，胜利是成功记录下它。

## 五、技术实现

```
blue-ice/
├── index.html          页面结构 / HUD / 开场 / 教程 / 手册 / 结算面板
├── css/style.css       玻璃拟态 UI、响应式（宽屏 / 窄屏 / 矮屏）
├── js/audio.js         Web Audio 程序化音效引擎（含混响、环境层、BOSS 心跳）
├── js/render.js        冰层背景预渲染 + 粒子/光锥/冲击环/浮字特效系统
├── js/game.js          状态机、装置/敌人、波次、合成、交互、主循环、调试接口
├── README.md           本文件
└── tests/              验收脚本、报告、截图
```

- **画面**：离屏 Canvas 预渲染冰层（渐变 / 年代带 / 裂纹 / 气泡 / 体积光柱 / 暗角），每帧叠加动态气泡、冰晶闪烁、流动光子；`lighter` 混合做辉光，DPR 适配。
- **冰裂隙**：路径由二次贝塞尔采样成平滑曲线，绘制与敌人行进共用同一组点，不会出现「敌人走出轨道」。
- **切伦科夫蓝光**：光锥 + 多层冲击环 + 放射线 + 光点 + 全屏泛蓝，合成、BOSS 击破、胜利结算逐级放大。
- **音效**：全部实时合成，无音频文件；环境低音随波次紧张度变化，BOSS 加入心跳与低频轰鸣。
- **性能**：静态背景只生成一次，粒子池上限 460，无第三方库、无网络请求。
- **自动化测试接口**：`window.__ICE_DEBUG__`（`start / deploy / mergeAll / advance / state / godMode` 等），仅在控制台使用，不影响正常玩法；`advance()` 以固定步长驱动**真实游戏逻辑**，不依赖渲染帧。
